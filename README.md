# Бонусная система кофейни — кэшбэк бонусами

Веб-приложение (PWA): клиент открывает ссылку, входит через Telegram и добавляет карту на главный экран телефона. Отдельное приложение в App Store / Google Play не требуется.

**Правила (меняются в админке):**
- с каждой покупки, на любую сумму и любой товар, начисляется **5%** бонусами;
- **1 бонус = 1 ₽**;
- бонусами можно оплатить не больше **20% чека**;
- бонусы начисляются с суммы, которую клиент реально оплатил деньгами (за вычетом списанных бонусов).

Пример: чек 500 ₽, у клиента 120 бонусов. Списать можно до 100 (20% от 500). Клиент платит 400 ₽ и получает 5% от 400 = 20 бонусов. Баланс: 120 − 100 + 20 = 40.

## Запуск

Нужен только Python 3.9+ (устанавливать библиотеки не нужно).

- Windows: двойной щелчок по `start.bat`
- или в терминале: `python server.py`

При первом запуске в консоли появятся **пароль администратора** (он же сохранится в `config.json`) и **PIN тестового бариста**.

| Адрес | Для кого |
|---|---|
| `http://localhost:8080/` | клиенты — баланс и QR-код |
| `http://localhost:8080/barista` | бариста — сканер и ввод чека |
| `http://localhost:8080/admin` | владелец — точки, сотрудники, клиенты, статистика, правила |

Без токена бота работает **тестовый вход по имени** — удобно для проверки.

## Как это работает

1. Клиент показывает QR-код (обновляется каждые 30 секунд — скриншот не поможет). Рядом номер карты и 6-значный код на случай, если сканер не работает.
2. Бариста сканирует QR камерой (или вводит номер и код) и видит баланс клиента.
3. Вводит **сумму чека**. Если клиент хочет оплатить бонусами, вводит количество или жмёт «Максимум». Экран сразу показывает, сколько платить и сколько бонусов будет начислено.
4. «Провести покупку» — клиент получает уведомление в Telegram.

Лимит списания = меньшее из двух: баланс клиента и 20% чека. Сервер перепроверяет все расчёты сам.

### Защита и отмена
- QR подписан и быстро устаревает. Все операции пишутся в журнал: кто, когда, на какой точке.
- Защита от двойного нажатия: одинаковая сумма для одного клиента повторно не проводится в течение 30 секунд.
- Максимальный чек ограничен (по умолчанию 20 000 ₽) — защита от опечаток.
- Бариста может отменить покупку своей точки в течение 15 минут, администратор — любую, без ограничения по времени. Бонусы пересчитываются. Отменить нельзя, если клиент уже потратил начисленные за неё бонусы (баланс стал бы отрицательным).
- Ограничено число попыток ввода PIN и пароля.

### Админка
- **Обзор:** выручка и покупки (сегодня и всего), начислено и списано бонусов, **бонусов на руках у клиентов** (ваше обязательство), разбивка по точкам и дням, журнал с отменой.
- **Клиенты:** поиск по имени, @username или номеру карты; баланс, число покупок, сумма покупок. Клик по строке — история клиента.
- **Точки, Сотрудники:** добавление и отключение, у каждого сотрудника свой PIN.
- **Правила:** процент начисления, доля чека для оплаты бонусами, максимальный чек, уведомления.

### Уведомления в Telegram
Бот пишет клиенту при покупке («Начислено +50, списано 20, баланс 34») и при отмене. Работает после подключения бота. Отключается галочкой в «Правилах». Без бота тексты печатаются в консоли сервера.

## Подключение Telegram

1. В Telegram откройте @BotFather → `/newbot`, получите **токен** и имя бота.
2. Там же: `/setdomain` → выберите бота → укажите домен вашего сайта (нужен **HTTPS**).
3. В `config.json` заполните `bot_token` и `bot_username` (без `@`), перезапустите сервер. Тестовый вход отключится сам.

## Выход в интернет

Нужен сервер с HTTPS (камера для сканера работает только по HTTPS). Подойдёт любой VPS: запустите `python server.py` за Nginx/Caddy с сертификатом, передавайте заголовки `X-Forwarded-For` и `X-Forwarded-Proto`. Порт можно задать переменной `PORT`.

Для быстрой проверки с телефона без сервера — `cloudflared tunnel --url http://localhost:8080`.

## Android-приложение (APK)

Скачать: https://killmite96-bot.github.io/coffee-bonus/ (страница со ссылкой и инструкцией; сам файл `Kofe-karta.apk` лежит в [Releases](https://github.com/killmite96-bot/coffee-bonus/releases)). Это оболочка над вашим сайтом: открывает его на весь экран, разрешает камеру для сканера QR и держит сессию. Данные и логика остаются на сервере, поэтому обновлять приложение при каждой правке сайта не нужно.

**Установка на телефон:** скопируйте APK на телефон, откройте его и разрешите установку из этого источника. APK подписан тестовым ключом, поэтому Android предупредит о неизвестном приложении, это нормально для сборки вне Google Play.

**Первый запуск:** приложение просит адрес сайта (например, `https://coffee.ваш-домен.ru`). Клиенты вводят адрес главной страницы, сотрудники — с `/barista` на конце. Адрес запоминается. Сменить его можно, очистив данные приложения (Настройки → Приложения → Кофе-карта → Хранилище → Очистить).

**Пересборка** (нужны Android SDK и JDK, Gradle не нужен):
```
cd android
python build_apk.py                                   # адрес вводится в приложении
python build_apk.py --url https://coffee.ваш-домен.ru  # адрес зашит в приложение
```
Для публикации в Google Play потребуется свой ключ подписи и сборка в формате AAB: это отдельный шаг.

**Важно:**
- Камера в приложении, как и в браузере, работает только на сайте с **HTTPS**. Для проверки по `http://` в домашней сети работает ручной ввод кода.
- Вход через Telegram устроен через перенаправление (не всплывающее окно), чтобы работать внутри приложения. Проверена подпись данных на тестовом токене, с реальным ботом ещё не пробовалось.
- В тестовом эмуляторе адрес компьютера — `10.0.2.2:8080`.

## Файлы

- `server.py` — сервер, API и база SQLite (`data/bonus.db`; её нужно бэкапить)
- `static/` — страницы клиента, баристы и админки
- `config.json` — настройки и секреты (**не публикуйте**)
